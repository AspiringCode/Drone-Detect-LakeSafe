# AI assistance disclosure

This project used **OpenAI Codex** and **Anthropic Claude** as material development
assistants. Their help included brainstorming, drafting specifications and task plans,
generating and refactoring UI and backend code, proposing and writing tests, performing
security and code review, debugging failures, and drafting submission documentation.
The assistance was substantially broader than grammar correction, and some code began
as AI-generated or AI-refactored work before student review and acceptance.

The 2026 Congressional App Challenge rules permit AI assistance only when it is fully
disclosed and the entry still demonstrates significant student contribution and
technical understanding. Official rules:
https://www.congressionalappchallenge.us/wp-content/uploads/2026/05/2026-CAC-Rules.pdf

## Student contribution and readiness checklist

Before submission, the student should personally confirm each item and add concise
examples where the application form permits:

- [ ] I selected the problem and honest product scope.
- [ ] I supplied requirements and design feedback instead of accepting every suggestion.
- [ ] I made the final safety, privacy, audience, and product decisions.
- [ ] I configured and understand the Supabase project, migrations, authentication, and
      server-only credentials used for the submitted demo.
- [ ] I ran the backend and dashboard, reviewed their behavior, and checked the final
      demonstration flow.
- [ ] I accepted, revised, or rejected proposed changes based on my own judgment.
- [ ] I can explain the reviewed-data snapshot, proxy-seed projection, shoreline-clipped
      planning, role/station authorization, public projections, simulation boundary,
      thermal pipeline, and real-device safety seam.
- [ ] I can make a small code change, add or update a test, and explain the result without
      relying on an AI tool to speak for me.
- [ ] I have reviewed the open-source licenses and attribution in this submission package.

This disclosure is a draft. The student must personalize it, remove any item that is not
true, add any other AI tools or uses, and verify the final wording before submission.
