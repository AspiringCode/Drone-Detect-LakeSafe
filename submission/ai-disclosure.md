# AI assistance disclosure

I used **OpenAI Codex** and **Anthropic Claude** as development assistants throughout
this project. They helped me brainstorm, write specifications and task plans, generate
and refactor backend and dashboard code, write tests, review the code for security
issues, debug failures, and draft documentation. Some code started as AI-generated or
AI-refactored work that I then reviewed, tested, and kept, changed, or rejected.

I chose the problem and the project's scope, made the safety, privacy, and product
decisions, set up the Supabase project, migrations, and authentication, and ran and
checked the backend, dashboard, and demo myself.

The 2026 Congressional App Challenge rules permit AI assistance when it is fully
disclosed: https://www.congressionalappchallenge.us/wp-content/uploads/2026/05/2026-CAC-Rules.pdf
